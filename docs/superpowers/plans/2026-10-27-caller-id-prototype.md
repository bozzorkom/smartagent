# Caller ID №08 Implementation Plan

> **For agentic workers:** использовать `superpowers:executing-plans` для последовательной реализации в текущей изолированной рабочей копии. Существующие незакоммиченные исправления Client 360° сохраняются. Публикация не входит в этап.

**Goal:** Интерактивный сценарий №08: разрешённый контекст звонка, честные варианты платформ и сохранение результата/задачи в общей CRM.

**Architecture:** Чистая модель вызовов в общей Workspace; один вызов проецируется в одну запись Today/Inbox, а его результат — в общую историю клиента. Новый CallerWorkspace использует существующий диалог и контролируемые черновики; системные концепты не создают ложных рабочих вызовов.

**Tech Stack:** Next.js/React/TypeScript/CSS текущего проекта; Node test runner; браузерная проверка. Новые зависимости не нужны.

**Spec:** `docs/prompt/8.md`, `docs/design/08-caller-id/design.md`. Пользователь явно выбрал веб-прототип вместо Figma без кода.

## Global Constraints

- Белый фон, чёрный основной CTA, существующая мобильная навигация; один сценарий №08.
- Только явные демо-примеры; никаких реальных вызовов, разрешений, микрофона, записи и отправки.
- Состояние провайдера, ручной результат, намерение набора и задача различаются.
- Контекст скрыт при блокировке/нет доступа/неоднозначности. Без неизвестных AI-параметров.
- Сроки вычисляются в Asia/Tashkent; данные и черновики — в памяти входа.
- Не менять исходную рабочую копию и не терять исправления Client 360°.

## Review Focus

1. Повтор/перестановка событий не создаёт дубликат или повторно открытый результат.
2. Общая линия и ответ коллеги не превращаются в личный пропущенный вызов.
3. Закрытие, ошибка и переход к клиенту сохраняют черновик и место возврата.
4. Скрытый номер и недоступная карточка не раскрывают личный контекст или ложный набор.
5. Повторное сохранение/конфликт не создаёт две задачи и не перезаписывает чужой результат.
