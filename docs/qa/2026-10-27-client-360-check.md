# Client 360° — браузерная проверка и исправления

Дата: 27 октября 2026 года. База: `8d37b2b`; рабочая ветка: `codex/client-360-qa`.

Продолжение после коммитов редактирования клиента, заметок и возврата из связанных действий. Проверен локальный прототип на `http://localhost:3000/`. Имена и записи создавались как демонстрационные данные. Старый отчёт Today не заменяется этим документом.

## Воспроизведённые ошибки и исправления

| Ошибка до исправления | Исправление и подтверждение |
|---|---|
| Заметка исчезала после «Задача → Назад к клиенту» | Черновики заметки, редактирования и фильтра истории хранятся по ID клиента. Браузерный тест упал до изменения и прошёл после него. |
| В запрос нового клиента попадало имя из отменённой задачи другого клиента | Черновики добавления разделены по типу и исходному клиенту/обращению. Своя незавершённая задача восстанавливается; новый клиент не наследует её данные. |
| В истории созданного из обращения клиента отсутствовала начальная запись | `clientHistory` включает подтверждённые связи по клиенту и связанным обращениям/задачам, исключает другой scope и явно другого клиента, убирает повтор ID. Исходный журнал не переписывается. Два новых теста сначала упали, затем прошли. |
| Создание командной задачи/обращения записывалось в личный журнал | Scope передаётся при создании истории. Регрессия `mine/mine` вместо `team/team` воспроизведена тестом и исправлена; подтверждена через UI руководителя. |
| Обработанное обращение вновь предлагало результат, перенос и закрытие | Показана история; повторное завершение недоступно. |
| «Написать» после обработки сообщения открывало только прежний результат | Быстрое действие открывает черновик; копирование доступно, повторное завершение старого обращения скрыто. Буфер совпал с введённым текстом, прежний результат не изменился. |
| После связанного действия фокус уходил на заголовок | Возвращаются фокус и позиция карточки; группа исходной кнопки раскрывается при необходимости. После закрытия основного диалога фокус возвращается к доступному инициатору либо Today. |
| «Обращение → Открыть клиента → Закрыть» требовало второго нажатия | Явный возврат очищает контекст дочернего действия. Браузерный тест прошёл после исправления. |

Дополнительно: отказ добавления не очищает форму; связанная командная задача сохраняет scope клиента; потеря демо-доступа скрывает список клиентов; из карточки/списка можно восстановить демо-доступ. Исправлены повреждённые русские подписи Today.

## Оставшийся объём полного задания

1. Несколько активных запросов, структурированные параметры/валюты и история смены запросов вместо одного текстового поля.
2. Контактные идентификаторы, несколько телефонов/каналов, неоднозначные совпадения и обратимое объединение. По имени контакты не объединяются.
3. Полная матрица видимости личных/командных данных и заметок, переназначение, архивирование, ограничение контакта и частичные ответы.
4. Все 50 edge cases, большой объём истории, ошибки отдельных источников, часовые пояса и восстановление после перезагрузки.
5. Условные блоки объектов, Smart Match, показов, сделок и AI — при готовности соответствующих возможностей.
6. Реальные screen-reader и Dynamic Type проверки, полная спецификация движения/контраста, Figma и handoff всех состояний.

Данные и черновики живут в памяти входа. Реальные SMS, звонки, отправка сообщений, серверные разрешения/хранение и синхронизация устройств не подключены. Offline и ошибки — переключаемые демо-сценарии, а не испытание реального отключения сети. Общая приёмка промпта №07 и оставшихся шагов плана Today не заявляется.
