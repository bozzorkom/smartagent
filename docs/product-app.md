# SmartAgent — спецификация iOS 26 приложения

Документ переносит веб-прототип SmartAgent (AI CRM для риэлторов Узбекистана) в нативное iOS 26 приложение на SwiftUI. Цель — сохранить **весь функционал, визуальный стиль и поведение** веб-версии, адаптировав их под системные паттерны iOS (Liquid Glass, Tab Bar, Sheets, SF Symbols).

Источник правды — текущий веб-прототип: `index.html`, `src/style.css`, `src/main.js` и модули в `src/`.

---

## 1. Продукт в одном абзаце

SmartAgent — рабочее место агента недвижимости и владельца агентства. Он собирает обращения из Telegram/OLX/Instagram и звонков, превращает их в клиентов и запросы, автоматически подбирает объекты (совпадения), мониторит рынок через TG Радар, ведёт показы, сделки и договоры, а владельцу даёт панель решений по команде. AI помогает с описаниями, оценкой, публикацией, документами и голосовой записью.

**Область:** интерактивный прототип. Все данные — демо, хранятся в памяти/локально до перезапуска. Нет реальной отправки сообщений, звонков, оплат и серверной авторизации. Любое «отправить/позвонить/опубликовать» — демо-действие с тостом и записью в журнал.

**Языки:** русский (основной) и узбекский (латиница). Все строки — через `Localizable.xcstrings`, ключи для ru/uz.

---

## 2. Принципы стиля

1. **Монохром + смысловые акценты.** Интерфейс почти полностью ахроматический (чёрный/белый/серые). Цвет появляется только для статуса: успех, предупреждение, ошибка — и для брендов каналов.
2. **Плотность и спокойствие.** Мелкая типографика (11–15 pt), много воздуха вокруг карточек, тонкие границы 0.5–1 pt вместо теней.
3. **Пилюли везде.** Кнопки, поля ввода, сегменты, чипы и бейджи — полностью скруглённые (capsule). Карточки — 16 pt.
4. **Цифры — табличные.** Цены, счётчики, проценты всегда `monospacedDigit()`.
5. **Стекло для хрома.** Шапка, таб-бар и нижние панели — полупрозрачные с blur (в iOS 26 — системный Liquid Glass).
6. **Один главный CTA на экран.** Чёрная (primary) кнопка — только для главного действия; остальное — secondary/outline/ghost.
7. **Каждое действие оставляет след.** Тост + запись в журнал/таймлайн.

### 3.2 Типографика

Веб уже использует системный стек `-apple-system / SF Pro Text / SF Pro Display` и `SF Mono` — в iOS это нативные шрифты.

- Межбуквенный интервал: текст −0.006 em, заголовки H1–H3 −0.022 em (`.tracking(-0.4)` для 20+ pt).
- Заголовки: `text-wrap: balance` → в SwiftUI `.multilineTextAlignment(.leading)` + `.lineLimit(2)`.
- Все числа: `.monospacedDigit()`.

| Роль | Веб | iOS |
|---|---|---|
| Заголовок экрана | 20–24 px semibold | `.title2.weight(.semibold)` / Large Title в навбаре |
| Заголовок диалога | 20 px semibold | `.title3.weight(.semibold)` |
| Цена объекта | 18 px semibold, tight | 18 pt semibold, monospacedDigit |
| Цена на карте | 15 px semibold | `.subheadline.weight(.semibold)` |
| Основной текст | 14 px | `.subheadline` (15 pt) |
| Кнопки | 14 / 13 / 12 px medium | `.subheadline.weight(.medium)` / `.footnote` |
| Вторичный текст | 12–13 px | `.footnote` |
| Бейдж, подпись | 11 px medium | `.caption2.weight(.medium)` |
| Метка секции | 11 px semibold UPPERCASE, +0.06 em | `.caption2.weight(.semibold)`, `.textCase(.uppercase)`, `.tracking(0.6)`, `mutedForeground` |
| Kbd / код | SF Mono 10 px | `.caption2.monospaced()` |

Поддержать Dynamic Type: размеры выше — базовые для `Large`, использовать семантические стили.

### 3.4 Размеры и отступы

- Сетка 4 pt. Типичные отступы: 8 / 12 / 16 / 20 / 24.
- Кнопка: высота 36 (default), 32 (sm), 28 (xs); иконка-кнопка 36×36 / 32×32. **Для iOS минимальная зона касания 44×44** — визуал можно оставить, `contentShape` расширить.
- Поле ввода: 36 (в формах — 44), горизонтальный padding 14.
- Сегмент: контейнер padding 2, кнопки h 28, padding 12.
- Чип: h 28, padding 10.
- Таб-бар: 64 pt + safe area. Шапка: 64 pt.
- Иконки: 16 pt, stroke 1.75 (lucide) → SF Symbols `.font(.system(size: 16, weight: .regular))`.

### 3.5 Анимация

| Что | Веб | iOS |
|---|---|---|
| Нажатие кнопки | scale 0.98, 150 ms | `.buttonStyle` с `scaleEffect(0.98)` + `.snappy` |
| Нижний шит | 280 ms, cubic-bezier(0.32, 0.72, 0, 1) | системный `.sheet` с detents |
| Появление экрана/строк | fade + translateY 8 pt | `.transition(.opacity.combined(with: .offset(y: 8)))` |
| Переключатель | 220 ms с лёгким перелётом | `.spring(response: 0.25, dampingFraction: 0.7)` |
| Микрофон записи | кольцо scale 1→1.75, opacity 0.22→0 | повторяющаяся `phaseAnimator` |

### 4.1 Composite-компоненты

- **Карточка объекта:** фото (галерея), категория, адрес/район, факты (комнаты · м² · этаж) 12 pt tabular, цена 18 pt + период 11 pt, статус/бейджи, нижняя строка действий через разделитель.
- **Карточка клиента:** аватар, имя, бюджет, район, стадия, «следующий шаг», бейдж просрочки.
- **Карточка совпадения:** клиент ↔ объект, процент совпадения, причины (чипы «район», «бюджет», «комнаты»), действия «Отправить подборку» / «Скрыть».
- **Пост Радара:** источник (бренд-иконка), свежесть, автор (собственник/агент), цена vs рынок, фото, контакты, «золотой» объект, кнопки «Связаться», «В объекты».
- **Строка очереди «Сегодня»:** тип (звонок/показ/просрочка/обращение), время, причина, одна главная кнопка.
- **Мастер (wizard):** шаги сверху, кнопки «Назад/Далее» в стеклянной нижней панели, обязательная галочка подтверждения на последнем шаге.

## 5. Навигация

### 5.1 iPhone — Tab Bar (Liquid Glass)

5 вкладок, как в мобильной веб-навигации:

1. **Сегодня** (`sun.max`)
2. **Входящие** (`tray`) — бейдж «требует ответа»
3. **Календарь** (`calendar`) — бейдж показов на сегодня
4. **Клиенты** (`person.2`)
5. **Ещё** (`ellipsis`) — список остальных разделов с подсказками-хинтами

Раздел «Ещё» (как веб-шит `#more`): Звонки · Уведомления · Сквозная демонстрация · Панель владельца · Самозапись клиентов · AI инструменты (NEW) · Совпадения (12) · Радар (LIVE) · Сделки (3) · Объекты · Аналитика · Настройки. Каждая строка: иконка, название, хинт (например «6 площадок · 312 от собственников»), бейдж.

**Быстрая запись голосом** — плавающая кнопка-микрофон / `tabViewBottomAccessory` в iOS 26, доступна с любого экрана.

### 5.2 iPad — `NavigationSplitView`

Боковая панель 256 pt (`sidebar`): логотип «b» в чёрном квадрате radius 10, «SmartAgent / Astor Realty · Pro», кнопка «Быстрая запись · Голосом», список разделов с бейджами, внизу карточка «Комиссия в октябре $7 840 / цель $12k» с прогрессом 65%.

### 5.3 Шапка

Стеклянная, 64 pt: заголовок раздела, поиск/командная палитра, уведомления, аватар с меню аккаунта (профиль, тема, язык ru/uz, роль — для демо переключение агент/владелец).

### 5.4 Роли

- **Агент** — рабочие разделы.
- **Владелец/руководитель** — дополнительно «Панель владельца», команда, переназначение, аналитика агентства.
Переключение ролей — в меню аккаунта (демо).

## 6. Функционал по разделам

Для каждого раздела: переносить все сценарии веб-версии; ниже — обязательный минимум.

### 6.1 Сегодня
- Утренний бриф и «что произошло ночью» (ночные лиды).
- Единая рабочая очередь: звонки, показы, просрочки, новые обращения, ответы собственников — с причиной и одной главной кнопкой.
- Чек-лист активации (первые шаги, подключение Telegram).

### 6.2 Входящие
- Обращения из каналов (Telegram, OLX, Instagram, звонки, самозапись).
- Фильтры «требует ответа», по каналу, по ответственному.
- Действия: ответить (демо), создать клиента, создать запрос, назначить сотрудника, отметить как обработанное.
- Диалог с ботом клиента (просмотр переписки, передача человеку).

### 6.3 Календарь
- День/неделя, показы, звонки, перезвоны.
- Создание показа (клиент + объект + время), подтверждение, перенос, отмена.
- Полный цикл показа: до → во время → итог (outcome) → следующий шаг; предупреждение собственника о показе.

### 6.4 Клиенты
- Список с фильтрами (стадия, бюджет, район, ответственный, просрочка).
- Профиль: контакты, запрос(ы) и их статус, жизненный цикл, активности (план/факт), шортлист, совпадения, история, CSAT.
- Действия: позвонить (демо + выбор итога звонка), написать, запланировать активность, отправить подборку, закрыть шортлист, архивировать.

### 6.5 Объекты
- Каталог всех типов недвижимости: сегменты категорий со счётчиками, фильтры (шит снизу на весь экран), сортировка, список/сетка/карта.
- Карта (MapKit): ценовые пины, кластеры, районы Ташкента, карточка объекта снизу.
- Карточка объекта: медиа, факты, доступность, CMA (оценка), сравнение, история цены, показы, подходящие клиенты, жизненный цикл.
- Создание/редактирование объекта (мастер), проверка достоверности описания.

### 6.6 Совпадения
- Движок совпадений клиент ↔ объект с процентом и причинами.
- Новые совпадения, прогресс по клиенту, алерты.
- Отправка подборки (внешняя страница подборки — демо-превью).

### 6.7 Радар (TG Радар)
- Лента постов с 6 площадок, статус LIVE, свежесть, кластеры дублей.
- Фильтры: от собственников, цена ниже рынка, «золотые», район.
- Пост: фото, файлы, автор, контакты, приманки/подозрительные, оценка цены.
- Запросы покупателей с рынка, совпадения с вашими клиентами, обновление поста.
- Действия: связаться, добавить в объекты, отметить качество.

### 6.8 Сделки и договоры
- Воронка сделок (3 активные), этапы, нотариус, задаток.

### 6.12 Панель владельца
- Очередь решений: входящие обращения, конкретные причины внимания, переходы к действию; «нет следующего шага» определяется по запланированным активностям.
- Нагрузка команды: раскрываемая карточка сотрудника — обращения, клиенты, действия на сегодня, просрочки, показы, сделки.
- Переназначение с контекстом: текущий ответственный, связанные действия, нагрузка получателя, обязательная причина → запись в журнал. Связанные сделки/объекты автоматически не передаются.

### 6.15 Сквозная демонстрация
- Пошаговый сценарий: обращение → клиент → подборка → показ → сделка, с подсветкой текущего шага.

### 6.16 Настройки

### 6.17 Сквозные функции
- **Быстрая голосовая запись:** микрофон → распознанный текст → AI предлагает сущности (клиент/объект/задача) → подтверждение.

- **Копирование** (телефоны, ссылки подборок) с подтверждением.

## 7. Адаптация под iOS 26

- Таб-бар, навбар, тулбары — системные с Liquid Glass; кастомные стеклянные панели — `.glassEffect(.regular, in: .capsule)`.
- Модальные окна — `.sheet` с detents; фильтры и карта — `.large`; подтверждения — `.confirmationDialog`.
- Свайпы по строкам: `.swipeActions` (позвонить, выполнить, перенести, архив).
- Контекстные меню: `.contextMenu` на карточках объектов/клиентов.
- Pull-to-refresh: `.refreshable` в Радаре, Входящих, Сегодня.
- Haptics: `.sensoryFeedback(.success / .warning / .selection)` на ключевых действиях.
- Карта: MapKit SwiftUI (`Map`, `Annotation`, `MapPolygon` для районов).
- Графики: Swift Charts.
- Виджеты (опционально): «Сегодня» и «Комиссия месяца». Live Activity — идущий показ.
- Архитектура: SwiftUI + `@Observable` стор на раздел, демо-данные из JSON в бандле (перенести из `src/data.js`, `src/property-demo-data.js`).

## 8. Доступность

- Контраст текста ≥ 4.5:1 (`mutedForeground` на `background` проходит).
- Зона касания ≥ 44×44 pt.
- VoiceOver: подписи для иконок-кнопок, бейджи читаются как часть названия («Входящие, 4 требуют ответа»).
- Dynamic Type до AX-размеров, Reduce Motion, Reduce Transparency (стекло → сплошной `background`).
- Состояния не только цветом: бейдж всегда с текстом.
