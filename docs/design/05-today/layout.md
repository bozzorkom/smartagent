# Today: мобильная композиция A–G

Статус: проектная спецификация шага 3. Не является подтверждением реализации или браузерной проверки. Основание: behavior.md, docs/prompt/5.md; текущие today.tsx и today.css. Размеры ниже — предлагаемые токены композиции, а не дословные требования исходного задания.

## Иерархия

A. Header: «Сегодня», дата рабочего дня, контекст пространства, профиль. Демо-метка сохраняется, но не оформляется отдельным баннером.
B. Источники: одна компактная строка статуса с раскрытием подробностей. Ошибки обозначаются словами и иконкой. Обновление доступно внутри подробностей, не занимает самостоятельную строку перед главным действием. При неполных данных предупреждение остаётся видимым.
C. Сводка: три равных кнопки — «Без ответа», «Пропущенные», «Задачи». Значения берутся из тех же наборов, что соответствующие полные списки. «Нет данных» не заменяется нулём. Счётчики разных типов не складываются.
D. Главное действие: заголовок «Начните с этого», одна карточка из общего ранжирования задач и обращений по behavior.md. Один заполненный чёрный CTA. Объяснение приоритета открывается вторичным текстовым действием.
E. Очередь внимания: до трёх карточек помимо главного действия; ссылка «Все обращения · N» открывает локальную панель. Карточка hero не повторяется в очереди, но остаётся в полном списке своего типа.
F. План дня: до трёх невыполненных задач. Ссылка «Весь план · N» открывает панель с группами «Просрочено / Сегодня / Позже / Выполнено». Выполненное не занимает основной экран.
G. Постоянная нижняя навигация и добавление. Кнопка добавления — контурная, чтобы не конкурировать с главным CTA. Ни навигация, ни уведомление не закрывают последний элемент списка.

## Первый viewport

Эталон: 393 × 852 CSS px, дополнительная проверка 375 × 812. Контейнер прототипа проверяется отдельно от ширины окна браузера.

Ориентировочный бюджет при обычном тексте: верхний отступ 20, header 88, промежуток 12, источники 56, промежуток 16, сводка 88, промежуток 24, заголовок 26, промежуток 12. Главное действие начинается примерно на 442 px. До нижней навигации видны событие, причина и основное действие при коротком содержимом.

Не задавать фиксированную высоту текстовых блоков ради бюджета. При предупреждениях, длинных именах и крупном шрифте допускается прокрутка. Приоритет — читаемость, а не искусственное размещение всего в одном экране.

## Унифицированная карточка

Порядок полей: тип и срок → клиент или идентификатор → факт → почему важно → источник и время → действие. Не показывать факт или источник, которых нет. Гипотеза AI всегда подписана отдельно.

| Тип | Что произошло | Почему важно | Действие |
| --- | --- | --- | --- |
| Пропущенный звонок | Входящий звонок не принят; время события | Нет подтверждённого результата контакта | Перезвонить; без номера — «Уточнить контакт» |
| Сообщение | Короткая выдержка и канал | Нет зафиксированного ответа | Открыть сообщение |
| Обещанный контакт | Задача и согласованный срок | Просрочено либо наступил срок | Связаться; отдельно записать результат |
| Проверка | Неполные сведения или гипотеза | Не хватает данных для решения | Проверить данные |
| Без ответственного | Заявка и время поступления | Некому выполнить следующий шаг | Назначить — только при разрешении |

Одна основная кнопка на карточку. Меню дополнительных действий имеет подпись для скринридера и область 44 × 44. Факт и причина не прячутся только в меню. Открытие карточки или копирование черновика не завершает работу.

## Полные списки

Панель открывается по счётчику или ссылке раздела. Заголовок объясняет выборку; показываются число записей, активные фильтры и пустое состояние. Закрытие возвращает фокус и позицию Today. Фильтр применяется ко всему набору, а не к трём видимым карточкам. Обновление не теряет выбор пользователя. Полный список имеет отдельную прокрутку и не удлиняет главную бесконечно.

## Предлагаемые токены

- Фон белый; основной текст #111; вторичный #666; поверхность #F7F7F7; граница #E8E8E8. Предупреждение #895415 с текстовой меткой. Не использовать цвет как единственный признак срочности.
- Существующее семейство шрифта проекта. Заголовок дня 30/34, раздел 20/26, заголовок карточки 17/23, основной текст 15/22, метаданные 13/18, подпись навигации 11/15 CSS px.
- Горизонтальные поля 20 px; на 320 px — 16. Вертикальные промежутки 8/12/16/24. Карточки: padding 16, radius 20, border 1. Сводка: gap 8, padding 12, radius 16.
- Главный CTA: min-height 48; остальные интерактивные области не менее 44 × 44. Нижняя навигация учитывает safe-area. Контент имеет запас снизу, уведомления не перекрывают действия.
- При крупном тексте сводка становится вертикальной, строки переносятся, карточки растут по содержимому. Не обрезать имена, статус ошибки и кнопки многоточием.

## Разница с текущим прототипом

1. Сейчас очередь ограничена четырьмя карточками; целевой предел — три.
2. Обновление и демо-метка занимают отдельные строки; нужно уплотнить верх без сокрытия достоверности данных.
3. Текущий полный список раскрывается в Today; целевой вариант — локальная панель с сохранением позиции.
4. Нужно ограничить план тремя задачами и оставить вход в полный план.
5. Чёрная кнопка добавления конкурирует с hero; требуется контурный вариант.
6. Текущий hero ещё требует общего ранжирования с задачами; одна визуальная перестановка этого не исправляет.
